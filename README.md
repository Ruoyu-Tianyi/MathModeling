# MathModeling Skill（V4.1）

**把赛题交给Agent → 输出可直接提交、可继续编辑的建模论文（Word）**（含模型推导、可运行代码、规范图表、摘要与参考文献）。适用于国赛（CUMCM）、美赛（MCM/ICM）及同类赛事，面向 所有支持 SKILL.md 规范的 AI Agent 运行。

## 功能特性

- **五阶段流水线，各设质量门禁**：审题立项 → 数据获取 → 建模求解 → 论文写作 → 校验交付
- **B/C 双赛道分流（V3）**：P0 判定清单逐问计分 + 用户确认后进入专属路径——B 型（机理/优化）走无噪声验证、多解性枚举、噪声地板等检验武器；C 型（数据驱动）走一键 EDA + 评价/预测/统计/优化决策树
- **题型→模型路由**：评价 / 预测 / 优化 / 机理 / 数据分析五大类，每问"主模型 + 对比基线"，拒绝模型堆砌
- **真实数据接入**：内置数据源路由表，金融/宏观数据自动路由到 Wind、Gildata、iFinD、World Bank、IMF、SEC、Yahoo Finance 等数据插件；取不到的数据走可复现仿真并在论文中声明，**严禁编造数据**
- **强制质量项**：每问必须含模型检验与灵敏度分析；摘要最后定稿且必须含具体数值结果
- **国赛排版规范内置**：字体字号、页边距、三线表、图表题注、摘要页格式封装为 `references/format-spec.md`，一键生成合规 Word
- **Word 优先交付**：`build_docx.py` 全离线将 paper.md 转为规范 docx（公式 mathtext 渲染嵌入、表格三线表、图片居中题注），可直接在 Word 中编辑微调；PDF 按需经本地 MathJax + Chrome 无头出片
- **自动化工具**：项目脚手架一键生成目录；提交前检查器自动拦截章节缺失、图表未引用、占位符残留等问题

## 使用

安装后对 AI 说：

> 用数模技能做这道题 + [赛题文本/PDF]

工作流产出：

```
<项目名>/
├── problem/      # 赛题原文
├── data/         # 原始数据 + SOURCES.md（来源可溯）
├── code/         # q1_*.py, q2_*.py ... 每问独立可运行
├── figures/      # 规范图表
├── results/      # 数值结果
└── paper/paper.md → paper.docx (+ paper.pdf 按需)   # 可提交论文
```

脚本独立用法：

```bash
# 初始化比赛项目（美赛用 --lang en）
python scripts/scaffold.py --name my-contest --lang zh

# 提交前检查（0 error 才通过）
python scripts/precheck.py paper/paper.md --lang zh

# 生成国赛规范 Word
python scripts/build_docx.py paper/paper.md
```

## 设计原则

- 先计划后动手：P0 的《问题分析》是唯一计划来源
- 优先级：摘要质量 > 模型检验/灵敏度 > 图表规范 > 模型复杂度
- 数据铁律：不编造数据、不编造文献、不编造数据库返回值

### V4（2026-08-06，全链路深度升档实战 + 方法论回填）

源自回测终稿复盘："正文 12 页够了，但模型全停在 L1 套用层"。V3.8 把厚度立为门禁，V4 把门禁兑现——以 2022 C 题为靶场完成 A–E 五项数学深度升档，并把实战中验证有效的方法沉淀回 skill 文档：

- **Q1 反演模型理论化**：比例反演从"做法"升级为"估计量"——无偏性论证、CLT ±2σ 预测区间、退化讨论（未风化样本为 0 时模型失效的边界）；留一经验覆盖率 91.1%/91.2% 与名义 95% 对照，轻微软覆盖源于成分厚尾，如实讨论
- **Q2 阈值解析互验 + 聚类三法对比**：搜索阈值 5.46% 用两条独立路径核验——实测类间间隙构成不敏感区间 [1.62, 9.30]（区间内任何阈值等价）、高斯 QDA 解析边界 1.99 + 理论错误率 0.92%；并证明 LDA 中点判据因方差悬殊（σ₂/σ₁≈29）失效，决策桩单侧阈值的必然性写透。亚类划分补 Ward/GMM 对比：高钾 ARI=1.000（结构稳定），铅钡 ARI 0.589/0.476（对算法中等敏感，如实降格结论强度）
- **Q3 升档三证据投票**：双证据（规则+质心）升级为规则 + 最近质心 + LDA 判别（判别函数全推导，留一错误率 1.49%），分层 bootstrap（B=500）给出逐件归属后验频率。**结论级变化**：A5 由"存疑"改判铅钡（三法 2:1 + 后验 0.98）、A8 由"铅钡"改判存疑（LDA 反向 + 后验仅 0.27）——深度方法不是装饰，它改写了答案
- **Q4 Fisher z 保守定位（诚实统计）**：类别间 91 对关联差异逐对 Fisher z 检验 + FDR 校正——|Δρ| 最大 0.80 但校正后无一过 0.05（最小 0.054），结论从"差异显著"降格为"描述性证据 + 功效分析佐证样本量不足"。宁可保守不可夸大，这是评审最看重的统计素养
- **检验节功效分析**：类型×风化卡方在实测效应 w=0.344、n=58 下功效 74.6%（略低于 0.8 惯例，给出达标样本量约 75 件）；高钾 SiO₂ 组间差异 δ=3.55σ 功效≈100%——主结论检验效力充分，边缘结论的保守定位均由功效解释
- **方法论回填（track-c-modeling.md）**：新增四条实战验证过的武器——Fisher z 差异检验（含保守定位话术）、检验功效报告规范、阈值规则解析互验双路径、分类鉴别三证据投票 + bootstrap 置信度，均附 2022 C 题实测数字
- 成果：正文 12→17 页（全文 50→62 页），display math 7→15，图 10→12 张，V3.8 厚度门禁 WARN 全部消除；precheck 0 error 通过

### V3.9（2026-08-06，图防重叠 · 公式编号 · 题注间距 · 伪数学门禁）

源自终稿逐项评审反馈：图内文字重叠、核心公式无标准 LaTeX/无编号、题注与正文挤在一起、散文伪数学混排。本轮四处修复 + 两处鲁棒性加固：

- **图防重叠（scaffold.py）**：`_boost_fonts` 放大系数封顶 1.5（只放大字形不改布局，过度放大必重叠——V3.7.1 回归根因）；放大 >1.15 且 x 刻度 ≥6 个时自动旋转刻度 40°；`flow()` 流程图改为**自缩放**——先按基准字号估算图宽推出放大系数，再按放大字号重新布局（盒宽/间距/坐标同步缩放），布局一开始就为终稿字号设计，并打标跳过事后 boost
- **公式自动编号（build_docx.py）**：`$$...$$` display math 全文连续自动编号 (1)(2)…，单行居中 + 编号右端贴页边，`\tag{}` 可手动覆盖；修复 `\t（n）` run 跟在 `m:oMathPara` 后被 Word 丢弃的 bug（此前编号从未真正渲染）
- **题注间距（build_docx.py）**：表题段前 6pt/段后 3pt，图题段前 3pt/段后 6pt——题注不再与正文/图表挤在一起
- **伪数学门禁（precheck.py）**：散文中三类伪数学逐行 WARN——下划线伪下标（`p_FDR`→`$p_{\mathrm{FDR}}$`）、Unicode 数学字符（`χ²`→`$\chi^2$`）、裸统计量（`p=0.01`→`$p=0.01$`）；图片路径/行内代码/文件名豁免；math-writing.md 新增公式排版纪律（`\frac`/`\sum`/`\mathrm`、矢量粗体、统计量一律行内公式）
- **鲁棒性加固**：① 单行 `|..|` 不再被吞成一行两列畸形表（`|ρ|` 绝对值写法放行，真表格须表头+分隔行两行）② publish 导出 PDF 前先删陈旧文件并按 mtime 校验新鲜度——陈旧 PDF 掩盖 COM 导出失败的问题不再发生（本次目检即被此坑过一次）

### V3.6（2026-08-05，贝叶斯与软聚类：C 赛道"深刻档"补全）

源自回测复盘 D 级观察——此前"贝叶斯个体化预测 / 混合模型聚类"只能写进论文"改进"节，现已落成 skill 原生能力：

- **贝叶斯不确定性量化**：`stats_utils.bayes_linreg()`（NIG 共轭闭式解，纯 numpy，弱先验下后验均值≈OLS）+ `bayes_predict()`（t 预测分布逐样本可信区间）；截距模型即"类均值预测的贝叶斯升级版"。合成数据 200 次重复平均覆盖率 0.942（名义 0.95）；玻璃数据留一实测：高钾 0.935、铅钡 0.923 达标
- **GMM 软聚类**：`gmm()` EM 实现（full/diag 双协方差模式，空簇重置 + 协方差正则化）+ `gmm_select()` BIC 选 k；输出逐样本后验归属概率，max 后验 <0.7 即"过渡样本"——"存疑"从定性词变定量结论
- **小样本协方差纪律**（实测教训）：n ≲ k·d²/2 时全协方差过参数化、BIC 选出病态 k；`cov_type="diag"` 为小样本默认——diag 模式下高钾 BIC 与轮廓系数同选 k=2，训练集类型分离 ARI=1.0
- **第三证据角色**：规则法与距离法冲突时（2022 C 题 A5：规则→铅钡 vs 质心→高钾），GMM 后验作独立量化裁决（A5 后验 1.000 支持规则判定，分歧源于质心法受风化漂移影响）
- **track-c-modeling.md 新增两节**：预测类"贝叶斯不确定性量化"（先验纪律/区间覆盖率检验写法）、聚类节"软聚类路线"（协方差纪律/BIC vs 轮廓系数并列报告/后验过度自信警示）
