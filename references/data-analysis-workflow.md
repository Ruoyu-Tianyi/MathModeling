## 阶段 1：读取与清洗

赛题附件（Excel/CSV）读入 `data/raw/`，清洗后存 `data/clean/`，原始文件**永不覆盖**。

```python
import pandas as pd
df = pd.read_excel("data/raw/附件1.xlsx")   # 或 read_csv(encoding 先试 utf-8 再 gbk)
```

清洗 checklist（每条写进论文"数据预处理"小节）：
- **口径统一**：单位、日期格式、编码（UTF-8/GBK）、数值被存成文本（`pd.to_numeric(errors="coerce")`）
- **缺失值**：占比 <5% 且非关键列 → 删除；关键列 → 插补（均值/中位数/插值/前向填充），写明规则
- **异常值**：3σ 或 IQR 规则检出，结合业务判断删除或截尾，**写明阈值与处理条数**
- **重复行**：`df.duplicated().sum()`，删除并记录
- **量纲**：多指标建模前标准化（z-score）或归一化（min-max），在论文中说明

清洗动作全部记录到 `data/SOURCES.md`（原始行数 → 清洗后行数，各规则剔除条数）。

## 阶段 2：EDA

每张图必须回答一个具体问题，禁止无目的堆图。必备四张：

1. **分布**：直方图/箱线图——看偏态、离群、是否需变换
2. **相关**：相关系数矩阵热力图——初筛相关变量，注意 |r|>0.9 的共线对
3. **时序**（若含时间）：折线图 + 滑动平均——看趋势/周期/突变点
4. **分组对比**：按类别分组的箱线/小提琴图——看类间差异是否显著

EDA 结论列表化（"发现 1：……"），后续建模必须能对应引用。

## 阶段 3：统计与特征

- **显著性检验选择**：两组均值 → t 检验（先正态性 K-S/Shapiro）；多组 → ANOVA；类别关联 → 卡方；分布拟合 → K-S
- **相关 ≠ 因果**：论文中禁用"导致"，用"显著相关"
- **特征工程**：日期拆年/月/季度/星期；类别 One-Hot（高基数先归并）；滞后特征用于时序
- **数据泄漏红线**：预测模型的特征只能用预测时点之前的信息，划分训练/测试集按时间切分（非随机）

## 阶段 4：建模与决策

按 `references/problem-types.md` 数据分析类路由选模型（聚类/分类/回归/时序/优化），约束：

- 每问"主模型 + 一个基线"，报对比指标（分类：准确率/F1；回归：RMSE/MAE/R²；聚类：轮廓系数）
- 优化类问题（定价/补货/调度）：目标函数与约束必须由前面统计结果支撑（如需求分布、弹性系数），论文中画出"数据 → 参数 → 优化"的链条
- 灵敏度：关键参数（如需求均值 ±10%）扰动重解

## 常见坑清单

- Excel 合并单元格/多级表头：`header=[0,1]` 或先 `skiprows`，别硬读
- 类别高基数（成百上千个 SKU）：先按规则归并（销量 Top N + 其他）
- 样本不平衡：分类任务报准确率前先报各类占比，必要时加权或重采样
- 伪相关：时序数据先差分/去趋势再算相关
- 中文列名绘图：走 `plot_setup`（CJK 字体已配），不要自己再设字体
