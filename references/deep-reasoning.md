## 推导稿制度（R2）

P0 完成后强制纸面推导先行， scaffold 已生成 `analysis/derivations.md` 骨架。结构：

```
# 推导稿（工作文档，不入最终论文）
## Q1 模型推导
### 定义与符号      —— 每个量先定义域与量纲
### 引理/中间结论    —— 可独立证明的小结论
### 推导            —— 定义 → 引理 → 可解形式，每步一句话理由
### 可解形式        —— 最终方程/算法输入输出（代码只许实现它）
### 六检查记录      —— 逐项打勾并写证据
```

铁律：**代码只实现推导稿的结论**，不许边写代码边想模型；推导稿改动要同步改模型叙述。

## 六检查协议（R1）

每项在推导稿中写 1–3 行证据，禁止只写"通过"：

1. **量纲一致**：每个公式两侧量纲相同；无量纲量（概率、相似度、归一化指标）显式标注
2. **退化检验**：取 1–2 个极端参数（0、∞、相等、对称），公式必须退化到已知/直觉结论；写出退化结果
3. **不变量**：找出系统守恒/不变量（总数、能量、面积、概率和=1），模型与数值结果必须保持
4. **界与误差**：优先给解析界（误差 ≤ f(参数)），其次才是数值仿真；写清界的来源与紧度
5. **良态性**：识别奇异构型（共线、零距离、分母趋零、矩阵病态、条件数大），说明如何检测与规避
6. **反例压力测试**：构造 ≥3 个对抗输入跑模型，记录通过/失败及修复（见红队清单）

## 分题型深化阶梯（R3）

交卷前自问：我停在第几级？能上一级就上一级。

| 题型 | 能用（L1） | 扎实（L2） | 深刻（L3） |
|---|---|---|---|
| 优化 | 建模求解得最优值 | 可行性/有界性论证 + 多算法对比 gap | 凸性/对偶下界 + 近似比或最优性证明 + 灵敏度解析式 |
| 统计/数据 | 回归/分类报指标 | 假设检验 + 置信区间 + 残差诊断 | 检验功效分析 + 因果识别讨论（混杂/选择偏差） |
| 机理/动力 | 方程建立 + 数值解 | 解析特例对照 + 平衡点存在唯一性 | 稳定性（雅可比/李雅普诺夫）+ 参数分岔/相图 |
| 评价 | 权重+打分排序 | 一致性检验 + 权重灵敏度 | 排名稳健性证明 + 公理化检验（单调性/独立性） |
| 预测 | 拟合 + 点预测 | 滚动验证 + 区间预测 | 误差传播链分析 + 可预测性上界讨论 |
| 几何/定位 | 方程求解 | 解的存在唯一性 + 歧义枚举 | 可辨识性严格证明 + 误差界分类讨论 |

## 红队对抗清单（R4）

模型跑通后主动攻击自己，≥3 个场景写入推导稿：

- **退化输入**：零、相等、共线/共面、对称构型（B 题的镜像歧义即此类）
- **极端比例**：参数跨 2–3 个数量级，看输出是否爆炸/消失
- **边界样本**：数据点恰在约束边界、分类面、定义域端点上
- **噪声注入**：输入加噪，输出扰动应连续有界（记录增益）
- **对抗构造**：刻意寻找使模型失效的输入；找不到也要写"尝试过程"

红队发现的问题不是丑闻是成果：写入论文"模型检验"或"误差分析"节，正是评审加分点（范文 Q1(2) 的误差界分类讨论由此而来）。
