## 国赛（CUMCM）结构

以官方模板（`assets/cumcm-template.docx`）章节顺序为准：

```
1. 题目（黑体三号居中）
2. 摘  要（黑体四号居中）+ 摘要正文 + 关键词 3–5 个
3. 问题重述（自己的话压缩，严禁抄题——会查重）
4. 问题分析（按问分节；每问：思路 + 模型选择理由，建议配流程图）
5. 模型假设（编号列出，每条给合理性说明）
6. 符号说明（三线表：符号 / 含义 / 单位；临时变量不必列入）
7. 模型的建立与求解（按 Q1…Qn 分节；每节：模型建立→求解→结果）
8. 模型的分析与检验（灵敏度分析、误差分析、模型检验放此节）
9. 模型的评价、改进与推广（优点必写，缺点数量少于优点，改进/推广选写但建议写）
10. 参考文献（GB/T 7714，正文有引用标注 [1]）
附录：支撑材料文件列表、源程序代码、详细证明、较大流程图
```

## 美赛（MCM/ICM）结构

```
1. Summary Sheet（摘要页，1 页以内，决定第一轮筛选）
2. Introduction（问题背景 + 工作概述）
3. Assumptions & Justifications
4. Notations
5. Model（按子问题分节：Development → Solution → Validation）
6. Sensitivity Analysis
7. Strengths & Weaknesses
8. Conclusion
9. References（正文引用 [1]）
（视赛题要求附 1–2 页 Letter/Memo/Report 给非技术读者）
```

## 摘要写作（第一权重）

四要素，按此顺序，一段式 200–400 字（美赛 ≤ 1 页）：

1. **问题**：一句话点明研究对象与任务。
2. **方法**：每问一句"针对问题X，建立了……模型，采用……算法求解"。
3. **结果**：每问给出**具体数值结论**（预测值、最优值、精度指标），禁止"结果较好"这类空话。
4. **结论/亮点**：一句模型检验结论（如 RMSE=…、灵敏度下排名稳定）+ 一句模型特色。

关键词 3–5 个：题型词 + 核心模型名（如"综合评价；熵权 TOPSIS；灵敏度分析"）。

写完正文后回头重写摘要；摘要中每个数字必须能在正文找到出处。

## 图表与公式规范

- 图：编号连续（图 1、图 2…），题注在图下方；正文先引用后出现（"结果如图 2 所示"）。中文图题、坐标轴带单位、图例清晰。
- 表：三线表，编号连续（表 1…），题注在表上方。
- 公式：LaTeX；重要公式编号 `(1)` 并在正文引用；符号首次出现即定义，与符号表一致。
- 代码：只放核心片段到正文（如有必要），完整代码进附录/支撑材料，注明运行环境。
- 数据：每个数据表注明来源（与 data/SOURCES.md 一致）；仿真数据明确标注"仿真生成"。

## 评审关注点

按权重排序，写作资源同向倾斜：

1. **摘要** — 第一轮筛选唯一依据。
2. **假设合理性与模型适配性** — 为什么用这个模型，假设是否支撑。
3. **检验与灵敏度** — 没有检验的论文直接降档。
4. **结果的具体性** — 有数字、有图、有对比。
5. **写作规范** — 结构完整、图表编号、引用规范。

常见失分点：抄题当问题重述；假设列了但正文不用；模型堆砌无主线；图表无正文引用；摘要无数字；参考文献格式混乱。
