## 评价类

**信号词**：评价、排序、打分、综合评估、指标体系、绩效、风险评级、选最优方案。

| 场景 | 主模型 | 基线/配套 |
|---|---|---|
| 指标权重 + 分层决策 | AHP（层次分析法）+ 一致性检验 CR<0.1 | 熵权法做客观权重对比 |
| 多方案多指标排序 | TOPSIS（理想解贴近度） | 熵权 TOPSIS / 灰色关联 |
| 主观模糊判断 | 模糊综合评价 | 熵权法定权重 |
| 权重完全客观化 | 熵权法 / CRITIC | 变异系数法 |
| 组合评价 | AHP+熵权组合权重 → TOPSIS | 单一方法对照 |

**检验**：权重敏感性（权重 ±10% 看排名翻转）、一致性检验（AHP）、排名稳健性。

## 预测类

**信号词**：预测、预报、趋势、未来 N 年、需求/销量/价格走势。

| 数据形态 | 主模型 | 基线 |
|---|---|---|
| 短序列、少数据、单调趋势 | 灰色 GM(1,1)（做残差与级比检验） | 线性/指数拟合 |
| 平稳时间序列 | ARIMA/SARIMA（ADF 定阶 + AIC/BIC 选参） | 指数平滑 |
| 长序列多特征 | 随机森林 / XGBoost 回归 | 多元线性回归 |
| 序列强非线性（数据充足） | LSTM/GRU | ARIMA 基线 |
| 生命成长/扩散（S 曲线） | Logistic / Bass 扩散 | 分段线性 |
| 区间/概率预测 | 分位数回归 / Monte Carlo 模拟 | 点预测 ± 残差带 |

**检验**：留出法/滚动原点验证，报 MAE/RMSE/MAPE；残差白噪声检验（Ljung-Box）；灵敏度 = 训练窗口长度扰动。

## 优化类

**信号词**：最优、最大/最小化、调度、选址、分配、路径、排产、资源配置。

| 问题结构 | 主模型 | 求解器/算法 |
|---|---|---|
| 线性目标线性约束 | LP / 整数规划 (ILP/MILP) | scipy.optimize.linprog / PuLP |
| 多目标冲突 | 加权法 / ε-约束 → Pareto 前沿 | NSGA-II（pymoo 可用则用） |
| 组合爆炸（TSP/调度/装箱） | 遗传算法 / 模拟退火 / 粒子群 | 贪心 + 局部搜索作基线 |
| 网络流/指派 | 最小费用流 / 匈牙利算法 | networkx |
| 动态多阶段 | 动态规划 / 强化学习思路 | 分阶段贪心基线 |
| 不确定环境下优化 | 随机规划 / 鲁棒优化（情景法） | 期望值模型 |

**检验**：与基线解/下界对比报 gap；约束可行性逐条验证；灵敏度 = 关键成本/需求参数 ±5%~20% 重解。

## 机理类

**信号词**：机理、演化、传播、扩散、动力学、平衡、稳定性、"解释为什么"。

| 系统 | 主模型 | 配套分析 |
|---|---|---|
| 连续动态系统 | ODE 方程组（SIR、Lotka-Volterra、Logistic 类） | 平衡点 + 稳定性（雅可比特征值） |
| 空间扩散 | PDE（热传导/反应扩散） | 数值解 + 网格收敛 |
| 随机演化 | 马尔可夫链 / 生灭过程 / 随机微分方程 | 平稳分布、首达时 |
| 离散个体交互 | 元胞自动机 / Agent 模拟 | 多 seed 统计 |
| 排队服务 | 排队论 M/M/c、M/G/1 | 稳态指标 vs 模拟 |

**检验**：解析解 vs 数值解对照；极端参数退化到已知结论；灵敏度 = 关键参数（如传染率 R0）扫描。

## 数据分析/统计类

**信号词**：分析、因素、相关性、影响程度、分类、聚类、异常、"找出规律"。

| 任务 | 主模型 | 基线/检验 |
|---|---|---|
| 影响因素显著性 | 多元回归（逐步 + VIF 查共线性） | 随机森林特征重要性 |
| 降维 | PCA / 因子分析（KMO>0.6） | 相关矩阵热力图 |
| 分类 | Logistic / SVM / XGBoost | 混淆矩阵 + ROC-AUC |
| 聚类 | K-Means（肘部法定 k）/ 层次聚类 | 轮廓系数 |
| 异常检测 | 3σ / IQR / Isolation Forest | 业务规则复核 |

**检验**：交叉验证报均值±方差；显著性报 p 值与置信区间；可视化先行（分布、相关、时序）。

## 组合信号

国赛/美赛实际赛题常为"A问评价 + B问预测 + C问优化"组合。处理：每问独立判型、独立模型，但用**统一数据管线**和**统一符号表**；C 问常消费 B 问预测结果作为优化输入——在论文中画出问题间数据流图。
