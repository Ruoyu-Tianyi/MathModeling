## B 题思维总纲

1. **推导稿即正义**：B 题几乎没有"试模型"的空间，`analysis/derivations.md` 必须推到可解析求解或可直接编码的封闭形式，代码只许翻译推导稿（R2 铁律）。
2. **无噪声先验**：任何模型先在**理想/无噪声条件**下验证——误差必须降到机器精度量级（如 1e-13），证明模型与代码实现本身是对的；再加噪声讨论性能。两步混做是 B 题最常见的翻车点。
3. **退化检验当定理用**：把参数推向极端（距离→0、角度→90°、数量→1），模型必须退化到已知的简单结论，退化结果写进论文"模型检验"。

## 几何 / 测量 / 定位类

**信号**：坐标、方位、距离测量、定位、覆盖、几何构型。

### 建模要点

- **先建坐标系再谈公式**：论文第一图永远是坐标系定义图（用 `plot_setup.draw_circle / mark_point / mark_angle`），所有符号在图上可见
- **观测方程写全**：每个观测量 = 几何关系的显式函数，列出方程个数 vs 未知数个数（可解性分析）
- **多解性是评审区分度所在**：测量方程非线性时必有**多解 / 镜像解**问题——枚举对称性（如关于基线的镜像）、给出解的个数定理或枚举算法、讨论"需要多少额外约束才能唯一解"。实战经验：m 个独立观测方程常给出有限个一致解，**把解的个数随 m 的变化做成表格**，是极强的论文亮点
- **先验信息形式化**：名义位置、已知高度、构型约束等都写成约束条件或先验分布，量化其贡献（如"加入名义先验后 168/168 样本收敛到真解"）

### 求解与迭代收敛

- 非线性最小二乘（Levenberg-Marquardt / Gauss-Newton）：初值敏感性必须分析——用先验给初值，报告收敛轮数与收敛后残差（如 15 轮迭代 12.01 → 2.3e-7 m 的收敛曲线，图 + 表双呈现）
- **噪声地板（noise floor）**：给测量加 σ 噪声后，定位误差不再随迭代下降而停在某个量级（如 σ=0.1° → 误差地板 0.56 m）——这个地板值本身是核心结果，必须从误差传播公式解析推导 + Monte Carlo 数值验证，双证据
- **误差传播链**：测量误差 σ_θ → 位置误差 σ_x 的解析式（一阶泰勒 / 雅可比条件数），写成公式并数值验证；条件数大的构型指出并讨论

## 微分方程 / 动力系统类

- 方程建立三件套：守恒律 / 平衡关系 → 微分形式 → 定解条件（初值/边值），缺一不可
- 平衡点 + 稳定性：雅可比矩阵特征值，论文中给特征值计算过程而非结论
- 数值求解：scipy.solve_ivp（RK45），做**步长减半收敛验证**；有解析解的特殊情形必须对照
- 参数辨识：实测数据反推参数 → 最小二乘拟合 + 残差分析 + 参数置信区间

## 运筹优化 / 调度类

- **模型四要素写全再求解**：决策变量（定义域！）→ 目标函数 → 约束逐条编号 → 参数表。约束必须逐条解释物理含义
- **可解性预判**：变量与约束规模 → 直接 LP/MILP；组合爆炸 → 启发式（GA/SA/PSO）+ 贪心基线报 gap
- 启发式的纪律：固定 seed、报多次运行均值±方差、给出收敛曲线；**禁止只报单次最好结果**
- 灵敏度：关键成本/需求参数 ±5%~20% 重解，用 `scripts/sensitivity.py`

## 仿真模拟类

- Monte Carlo：明确"仿真什么随机性"——输入分布从哪来（题目/假设/拟合），假设的写进假设节
- 每次仿真报 N 次运行的均值 ± 置信区间，N 的选取要有依据（标准误 <1% 结果量级）
- Agent/元胞类：多 seed 统计，时空演化关键帧截图入论文

## B 题特有的检验武器

| 武器 | 做法 | 论文呈现 |
|---|---|---|
| 无噪声验证 | 理想数据下误差 ~1e-13 | 一句话 + 数值，证明实现正确 |
| 退化检验 | 极端参数 → 已知结论 | 模型检验节逐条列 |
| 多解性枚举 | 解个数随约束数变化 | 表格 + 讨论，强亮点 |
| 解析 vs 数值双解 | 同一问题两种解法互验 | 差异量级报告 |
| 噪声地板 | 误差传播解析 + MC 验证 | 收敛曲线图 + 地板值 |
| 收敛性 | 迭代轮数 / 步长减半 | 收敛曲线（横轴轮数，纵轴残差，对数轴） |

## B 题灵敏度重点

与 C 题（扰动权重/窗口）不同，B 题灵敏度对象是**物理参数与测量精度**：

- 测量误差 σ 扫描（如 0.01°~1°）→ 结果误差曲线，验证与解析误差传播的幂律关系
- 构型参数（基线长度、数量、分布形状）扰动 → 性能变化，回答"设计建议"类追问
- 先验强度（名义位置偏差 ±x%）→ 收敛率变化
- 分布假设更换（均匀 → 锥形 → 高斯）→ 结果稳健性（实战经验：分布形状改变后校准增益从 X 变为 Y，这类对比极具说服力）
