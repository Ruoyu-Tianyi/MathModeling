## 评价类：权重 → 合成 → 排序

### 决策树

```
权重来源？
├─ 纯主观（专家打分）     → AHP（必做一致性检验 CR<0.1）
├─ 纯客观（数据变异程度） → 熵权法（信息熵）/ CRITIC（含冲突性）
└─ 组合                  → AHP 主客观组合权重 w = α·w_AHP + (1-α)·w_熵，α 灵敏度扫描

排序方法？
├─ 指标可向量化为"距理想解远近" → TOPSIS（先正向化 + 归一化）
├─ 指标间有隶属度模糊性         → 模糊综合评价
└─ 指标量纲差异大且要保序       → 灰色关联分析
```

### 关键公式（论文必须写全推导链）

**熵权法**：对第 j 个指标，$p_{ij} = x'_{ij} / \sum_i x'_{ij}$（$x'$ 为归一化值），$e_j = -\frac{1}{\ln n}\sum_i p_{ij}\ln p_{ij}$，$w_j = (1-e_j)/\sum_j(1-e_j)$。注意 $\ln 0$ 处理：$p_{ij}=0$ 时该项按 0 计。

**TOPSIS**：正理想解 $A^+$、负理想解 $A^-$，贴近度 $C_i = D_i^-/(D_i^+ + D_i^-)$。指标先做**正向化**（成本型 → 效益型：$x' = \max - x$ 或 $1/x$，论文中说明选用及理由）。

**AHP 一致性**：$CI = (\lambda_{\max}-n)/(n-1)$，$CR = CI/RI < 0.1$；不满足必须调整判断矩阵并在论文中说明调整方式。

### 检验（缺一扣分）

- 权重扰动 ±10% 重排，报告排名翻转数（用 `scripts/sensitivity.py` 的 `sweep()`）
- 主模型 vs 基线（如熵权 TOPSIS vs 等权 TOPSIS）排名 Spearman 相关系数
- AHP 判断矩阵来自"文献 + 数据特征"双重依据，不许凭空填 1/3/5/7

## 预测类：时序与回归

### 时序路线（单序列）

```
ADF 平稳性检验
├─ 平稳        → ARIMA(p,d,0)，AIC/BIC 定阶，残差 Ljung-Box 白噪声检验
├─ 不平稳      → 差分后重来（d=1 不够再 d=2，很少需要）
├─ 强季节性    → SARIMA 或 Holt-Winters
└─ 数据 <30 点 → 灰色 GM(1,1)：级比检验 → 建模 → 残差/后验差比 C<0.35
```

深度学习（LSTM/GRU）仅当样本量 >500 且有明确非线性证据时使用，且必须配 ARIMA 基线对比；样本不够用了就是减分项。

### 回归路线（多特征）

1. **先做共线性**：VIF > 10 的变量剔除或合并（论文中列 VIF 表）
2. **主模型选择**：
   - 关系近似线性、要解释系数 → 多元线性回归（报系数 + t 检验 p 值 + 置信区间）
   - 非线性/交互复杂、要精度 → 随机森林 / XGBoost（报特征重要性 + SHAP 摘要图更佳）
3. **验证纪律**：时序数据按时间切分（禁随机划分防泄漏）；截面数据用 5 折交叉验证，报均值 ± 标准差
4. **指标**：RMSE / MAE / MAPE / R² 至少报三个；分类问题报 F1（不平衡数据先报类别占比）

### 检验

- 残差诊断四图（残差 vs 拟合值、Q-Q、残差直方图、残差时序）放附录
- 灵敏度 = 训练窗口长度 / 超参数（如树深度）扰动，报指标波动范围

## 统计推断类：相关 / 显著性 / 因果表述

- **相关选择**：正态连续 → Pearson；非正态或等级 → Spearman；类别-类别 → 卡方 + Cramér's V
- **显著性**：两组 → t 检验（先 Shapiro 正态性）；多组 → ANOVA + 事后 Tukey；非正态换 Mann-Whitney / Kruskal-Wallis
- **表述红线**：观察性数据只写"显著相关（r=…, p<0.05）"，禁止"导致/促进/提升"；确需因果方向时写"与……一致，提示可能的作用方向"
- **多重检验**：同时检验 >10 个假设时提一句 Bonferroni/FDR 校正

### 聚类与画像

- K-Means：肘部法 + 轮廓系数双证据定 k；特征必须先标准化
- 聚类后必做**画像表**：每类的特征均值对比 + 业务命名（如"高值低频型"），这是 C 题论文的加分点
- 检验：不同 seed 下聚类稳定性（ARI 系数 >0.8 视为稳定）

## 数据驱动优化类

C 题优化与 B 题优化的区别：**参数来自前面的统计分析**，不是题目直接给的。论文必须画出"数据 → 参数估计 → 优化模型 → 决策"的完整链条（用 `plot_setup.flow()`）。

- 需求/供给是估计出来的分布 → 随机规划或蒙特卡洛仿真优化（抽 N=1000 个场景求期望最优）
- 价格弹性、成本系数 → 回归估计，论文中给出估计区间，优化结果对区间端点各解一次（稳健性证据）
- 多目标（利润 vs 风险 vs 满意度）→ 加权法 + 权重灵敏度，或 Pareto 前沿图

## 成分数据（Compositional Data）纪律

化学成分百分比、配料比、支出结构等"各分量加和 ≈100%"的数据有特殊陷阱，处理不当结论会系统性偏掉：

- **空白语义先确认**：成分表的空白通常 = "未检测到"（应为 0），不是缺失值——用 `eda.py --blank-as-zero` 探查，论文中显式声明该处理
- **行和有效性**：赛题常给有效区间（如累加和 85%~105%），用 `--row-sum-range` 检出无效行并在预处理节说明剔除
- **闭合效应（spurious correlation）**：分量此消彼长导致相关分析失真——两个成分即使独立也会因"总和恒定"呈负相关。对策按深度三选一：
  1. 最低限度：论文中声明闭合效应存在，相关结论限定为"描述性关联"
  2. 标准做法：CLR 变换（$clr(x)_i = \ln(x_i / g(x))$，g 为几何均值）后再算相关/聚类/PCA
  3. 含 0 分量：CLR 前 0 值替换为小正数（如最小检出限的一半），说明替换规则
- **亚类划分/聚类**：优先在 CLR 空间做欧氏距离聚类；直接用原始百分比要说明理由
- **"反演/还原"类问题**（如预测风化前成分）：用比例关系而非绝对量建模（成分比迁移），结果再归一化回 100%

## C 题灵敏度与检验清单

| 环节 | 必做项 |
|---|---|
| 数据预处理 | 异常值规则改变（3σ → IQR）重跑主结果，报告是否翻转 |
| 评价 | 权重 ±10%、α 组合系数 0~1 扫描、方法间 Spearman 相关 |
| 预测 | 训练窗口扰动、超参扰动、与基线模型对比 |
| 优化 | 关键估计参数 ±10%~20% 重解（`sensitivity.py` 的 `sweep_multi()` + `tornado()`） |

## 论文写法要点

- EDA 发现必须**编号列表化**（"发现 1：……"），模型选择段落逐一回引（"针对发现 2 的非线性特征，选用……"）
- 每个模型一节内结构固定：**方法原理（含公式推导）→ 数据代入 → 结果 → 检验 → 小结**
- 三线表呈现：权重表、VIF 表、模型对比指标表、灵敏度结果表；图呈现：EDA 四图、Pareto 前沿、扰动曲线、聚类画像雷达图
- 灵敏度分析单独成节（通常放在"模型检验"或"稳健性分析"），有表有图有结论，不许一句话带过
